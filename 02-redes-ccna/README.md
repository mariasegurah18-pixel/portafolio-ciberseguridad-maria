#  Proyectos de Redes (CCNA)

##  Descripción
Configuración y simulación de redes utilizando Cisco Packet Tracer.

## Contenido
- VLANs
- Routing básico
- Segmentación de red /ACL
- DHCP/DNS/SSH/NTP/ICMP
- STP/LACP/HSRP/LLDP


## Objetivo
Aplicar fundamentos de redes para garantizar comunicación eficiente y segura en diferentes tipos de redes .

## Evidencia
(Aquí se incluyen archivos .pkt y capturas de pantalla)

## Aprendizaje
Las redes son la base de la ciberseguridad. Este conocimiento permite entender cómo se originan y se previenen ataques.
