2 paso 
Se tiene que crear una ACL para el trafico de http para eso tenemos que sumarizar las redes y luego crear la ACL esto se aplica al router fronterizo 

ip access-list extended Navegacion
 permit tcp 172.17.0.0 0.0.0.255 any eq 80
 permit tcp 172.16.0.0 0.0.3.255 any eq 80
 permit tcp 192.168.0.0 0.0.127.255 any eq 80
 permit tcp 172.17.0.0 0.0.0.255 any eq 443
 permit tcp 172.16.0.0 0.0.3.255 any eq 443
 permit tcp 192.168.0.0 0.0.127.255 any eq 443

ip access-list extended Respuesta
 permit tcp any 172.17.0.0 0.0.0.255 established
 permit tcp any 172.16.0.0 0.0.3.255 established
 permit tcp any 192.168.0.0 0.0.127.255 established

interface s0/0/0
ip access-group Navegacion out
 ip access-group Respuesta in
